Hi, I'm Alper.

An Embedded Linux engineer who spends an unreasonable amount of time trying to convince computers to boot.

I currently work in the automotive domain, where I deal with technologies such as Yocto, QNX, Android Automotive OS (AAOS) and Renesas based platforms. For some reason, I seem to enjoy working with systems that have absolutely no intention of cooperating.

My main areas of interest include:

- Contributing to the Yocto Project and OpenEmbedded ecosystem.
- Contributing to the Linux kernel using static analysis tools.
- Bringing Yocto support to SBCs that apparently decided they didn't need official support.
- Working with the Linux kernel, Device Tree, U-Boot, and Embedded Linux BSPs.
- Customizing and optimizing U-Boot, Linux kernel and root filesystem. Usually in the name of performance, security or reducing a few more megabytes.
- Secure Boot and other embedded Linux security mechanisms.
- OTA update systems.
- Trying to keep up with Modern C++ (C++20/23/26), because apparently C++17 wasn't complicated enough.

This blog is where I document what I learn, what I break, what I fix and occasionally why something worked perfectly yesterday but refuses to work today. Sometimes it's a technical deep dive. Sometimes it's a solution to a problem that took two days to solve and two minutes to explain.

If something here helps you learn something new, then the blog has done its job.
